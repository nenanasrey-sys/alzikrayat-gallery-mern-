# Alzikrayat Gallery

منصة ويب متكاملة مبنية بتقنيات **MERN Stack** لمشاركة الذكريات والصور وإضافة التعليقات التفاعلية عليها.

## التقنيات المستخدمة (Tech Stack)
- **Frontend:** React, Axios
- **Backend:** Node.js, Express.js, Multer
- **Database:** MongoDB Atlas, Mongoose
- **Version Control:** Git, GitHub

## أبرز المميزات (Features)
- عرض معرض الذكريات والصور مع اسم المستخدم والعنوان والتعليقات.
- إضافة تعليقات جديدة على الصور وحفظها في قاعدة البيانات.
- رفع صور جديدة وحذف الذكريات.
- تسجيل الدخول وإدارة الحسابات.
